# ❤️ A Letter Just For You

A romantic two-page handwritten-letter website.

## Folder structure

- `index.html`
- `style.css`
- `script.js`
- `assets/page1.jpg`
- `assets/page2.jpg`
- `assets/our-song.mp3` (optional — add your own song)

## Add your song

Put your MP3 file in the `assets` folder and rename it:

`our-song.mp3`

The browser may block automatic music playback, so the visitor should press Play.

## Test on your computer

Open `index.html` in a browser.

For best results, use VS Code + Live Server, or run a simple local server:

`python -m http.server 8000`

Then open:

`http://localhost:8000`

## Publish it for free

### GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders in this ZIP.
3. Open the repository's Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save.
6. GitHub will give you a public website link.

### Netlify
1. Create an account.
2. Use Netlify's manual deploy / drag-and-drop deployment.
3. Upload the `love_letter_website` folder contents.
4. Netlify gives you a public link immediately.

Do not remove the `assets` folder or the handwritten pages will not appear.
